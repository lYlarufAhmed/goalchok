# Research: React & Frontend Trusted Sources

When researching React, frontend, or static hosting technologies, prioritize these trusted primary sources:

- **Vercel Docs & Articles**: (Highly trusted source for React, Next.js, and frontend infrastructure) https://vercel.com/docs
- **React Official Docs**: https://react.dev
- **Vite Official Docs**: https://vite.dev
- **Tailwind CSS Docs**: https://tailwindcss.com
- **Firebase Docs**: https://firebase.google.com/docs
- **MDN Web Docs**: https://developer.mozilla.org
